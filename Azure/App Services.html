Azure App Services - Frequently Asked Questions

1. What is Azure App Service?

Azure App Service is a fully managed platform for building, deploying, and scaling web apps, APIs, and mobile backends.

2. Which programming languages are supported by Azure App Service?

It supports .NET, .NET Core, Java, Ruby, Node.js, PHP, Python, and more.

3. What deployment options does Azure App Service provide?

You can deploy using FTP, Git, GitHub, Azure DevOps, Visual Studio, or ZIP file deployments.

4. Can Azure App Service scale automatically?

Yes, it supports automatic scaling based on demand, including scaling out (adding instances) and scaling up (increasing instance size).

5. What is the difference between scaling up and scaling out?

Scaling up increases the resources (CPU, RAM) of a single instance, while scaling out increases the number of instances.

6. What types of apps can I host on Azure App Service?

Web apps, RESTful APIs, mobile backends, and even containerized apps using Linux or Windows containers.

7. Does Azure App Service support custom domains?

Yes, you can configure custom domains and SSL certificates for secure connections.

8. How does Azure App Service handle security?

It offers built-in authentication and authorization with providers like Azure AD, Google, Facebook, and more, plus SSL/TLS encryption and network isolation options.

9. What is the difference between App Service Plans?

App Service Plans define the compute resources your app runs on, including pricing tiers like Free, Shared, Basic, Standard, Premium, and Isolated.

10. Can I run Linux-based apps on Azure App Service?

Yes, Azure App Service supports both Windows and Linux environments for hosting apps.

11. What is deployment slot in Azure App Service?

Deployment slots let you deploy different versions of your app (e.g., staging, testing) and swap them without downtime.

12. How do deployment slots help in continuous deployment?

They enable you to validate changes in a staging slot before swapping to production, minimizing downtime and risk.

13. What is Azure App Service Environment (ASE)?

ASE is a fully isolated and dedicated environment for securely running App Service apps at high scale.

14. How do I monitor the health of my App Service?

You can use Azure Monitor, Application Insights, and logs for performance and diagnostic data.

15. Can Azure App Service integrate with databases?

Yes, it easily integrates with Azure SQL Database, Cosmos DB, MySQL, and other database services.

16. Does Azure App Service support containers?

Yes, you can deploy Docker containers or use Azure Container Registry with App Service.

17. What is the maximum size for an Azure App Service app?

Limits vary by plan, but typically up to 250GB of disk storage per app.

18. Can I use Azure DevOps with Azure App Service?

Yes, Azure DevOps integrates seamlessly for CI/CD pipelines deploying to App Service.

19. How is App Service billed?

Billing depends on the App Service Plan tier and the number of instances running, not on the number of apps hosted.

20. Can I configure auto-scaling rules in Azure App Service?

Yes, you can configure auto-scale based on CPU usage, memory, HTTP queue length, and custom metrics.

21. What are WebJobs in Azure App Service?

WebJobs allow you to run background tasks or scripts in the same App Service environment as your web app.

22. How does Azure App Service handle backups?

You can schedule automated backups for your app and its associated databases.

23. Can I secure my Azure App Service with Virtual Network integration?

Yes, App Service supports Virtual Network integration and private endpoints for enhanced security.

24. What is the difference between Azure Functions and Azure App Service?

Azure Functions is a serverless compute service for event-driven code, while App Service hosts full web apps and APIs.

25. Does Azure App Service support HTTP/2?

Yes, Azure App Service supports HTTP/2 for faster web performance.

26. Can I customize the runtime environment in Azure App Service?

Yes, especially when using Linux or containers, you can customize runtimes and dependencies.

27. What is Always On in Azure App Service?

Always On keeps your app running continuously, preventing cold starts for faster response times.

28. Can Azure App Service host multiple apps on a single plan?

Yes, you can host multiple apps under one App Service Plan, sharing the same resources.

29. How can I troubleshoot my Azure App Service app?

Use Application Insights, diagnostic logs, and Kudu console to debug and troubleshoot issues.

30. What compliance certifications does Azure App Service have?

Azure App Service complies with many standards including HIPAA, ISO, SOC, GDPR, and more.
