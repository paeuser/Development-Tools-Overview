JavaScript data types:

1. Primitive Types
Type	Description	Example
Number	Represents numeric values (integers and floats)	42, 3.14, NaN, Infinity
String	Represents text	"hello", 'world'
Boolean	Represents true or false	true, false
Undefined	Represents a variable that has not been assigned a value	undefined
Null	Represents the intentional absence of any object value	null
Symbol	Represents a unique and immutable identifier	Symbol('id')
BigInt	Represents integers with arbitrary precision (big integers)	123456789012345678901234567890n


2. Non-Primitive (Reference) Types
Type	Description	Example
Object	Collection of key-value pairs	{name: "Alice", age: 25}
Array	Ordered list of values	[1, 2, 3, 4]
Function	Callable objects	function() { return 1; }
Date	Represents dates and times	new Date()
RegExp	Regular expressions	/abc/i
...	Many more built-in objects
