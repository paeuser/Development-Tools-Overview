Angular Interview Questions & Answers

1. What is Angular?
Angular is a TypeScript-based open-source front-end web application framework led by the Angular Team at Google. It enables developers to build dynamic single-page applications using components, services, and a modular architecture.
2. What are components in Angular?
Components are the fundamental building blocks of Angular applications. Each component consists of an HTML template, a CSS stylesheet, and a TypeScript class that controls a part of the user interface.
3. What is Angular CLI?
Angular CLI is a command-line interface tool that helps automate development tasks such as project creation, configuration, building, testing, and deployment of Angular applications.
4. What is data binding in Angular?
Data binding in Angular is the synchronization between the model (component class) and the view (HTML template). It includes interpolation, property binding, event binding, and two-way binding using [(ngModel)].
5. What are directives in Angular?
Directives are classes that add additional behavior to elements in Angular applications. Structural directives like *ngIf and *ngFor change the DOM layout, while attribute directives like ngClass and ngStyle change the appearance or behavior of an element.
6. Explain Angular modules (NgModules).
NgModules are containers that group components, directives, pipes, and services that are related. The root module is usually AppModule, which bootstraps the Angular application.
7. What is Dependency Injection (DI) in Angular?
Dependency Injection is a design pattern Angular uses to supply components or services with dependencies they require. It promotes modularity and ease of testing by managing the creation and sharing of service instances.
8. What is RxJS and how is it used in Angular?
RxJS (Reactive Extensions for JavaScript) is a library for reactive programming using Observables. Angular uses RxJS extensively for asynchronous operations such as HTTP requests and event handling.
9. What are Angular lifecycle hooks?
Lifecycle hooks are methods that Angular calls at specific points in a component's lifecycle, such as ngOnInit(), ngOnChanges(), ngOnDestroy(), allowing developers to perform actions during those stages.
10. How does Angular handle forms?
Angular supports two types of forms: Template-driven forms (simple forms with directives in templates) and Reactive forms (more powerful, with explicit form model and validation logic in the component class).
11. What is Angular Router?
Angular Router enables navigation from one view to another within a single-page application. It supports features like lazy loading, route guards, and parameterized routes.
12. What is the difference between Observable and Promise?
A Promise handles a single event when an async operation completes or fails, whereas an Observable can handle zero or more events over time, supports operators, and can be cancelled.
13. What is Angular Universal?
Angular Universal is a technology for server-side rendering of Angular applications, improving performance and SEO by rendering pages on the server before sending them to the client.
14. How do you optimize an Angular application?
Techniques include Ahead-of-Time (AOT) compilation, lazy loading modules, using OnPush change detection strategy, minimizing bundle size with tree shaking, and avoiding unnecessary change detection cycles.
15. What are Angular Pipes?
Pipes transform data in templates. Angular provides built-in pipes like date, uppercase, and custom pipes can be created to format data display.
