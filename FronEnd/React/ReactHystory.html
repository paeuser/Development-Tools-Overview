History of React (Timeline)

Year Event / Version Description
2011 Internal Development Jordan Walke creates React at Facebook to manage complex UIs.
2013 Open-Sourced React is released at JSConf US with JSX and Virtual DOM.
2015 React Native & Redux React Native launches; Redux introduced for state management.
2016 React 15 Improved SVG support and performance enhancements.
2017 React 16 (Fiber) Major rewrite with Fiber architecture, better error handling, portals.
2018 Hooks Announced Hooks allow functional components to manage state and side effects.
2019 React 16.8 Hooks become part of stable release. Shift away from class components.
2020 React 17 No new features; improved gradual upgrade support.
2022 React 18 Introduced concurrent features, automatic batching, streaming SSR.
2023 React 18.1 Improved SSR hydration, bug fixes, and enhanced support for server components.
2024 React 18.2 Introduced React Server Actions for simplified server-client interaction, and improved Suspense capabilities.
2023–2025 Server Components & Edge Adoption of React Server Components and edge rendering (e.g. with Next.js).
Upcoming React 20 (Speculative) Expected improvements include further server components enhancements, simplified APIs, better performance, and more seamless integration with emerging web standards. Official release and features pending.
