Tricky T-SQL Questions with Sample Queries

Q1: What is the difference between INNER JOIN and OUTER JOIN?
INNER JOIN returns only matching rows. OUTER JOIN returns all rows from one table plus matching rows from another.
-- INNER JOIN SELECT e.Name, d.Name AS Dept FROM Employees e INNER JOIN Departments d ON e.DeptID = d.DeptID; -- LEFT OUTER JOIN SELECT e.Name, d.Name AS Dept FROM Employees e LEFT JOIN Departments d ON e.DeptID = d.DeptID;
Q2: What is a CTE and how is it different from a temp table?
CTE stands for Common Table Expression. It is a temporary named result set that exists only during the execution of a single query. CTEs make complex queries easier to read and maintain, especially for recursive queries or breaking queries into logical steps. Unlike temp tables, CTEs are not stored physically in the database.

Key Points:
  • CTE is temporary and disappears after the query finishes.
  • CTE can be recursive, allowing self-referencing queries.
  • Temp tables exist physically in the tempdb database and persist for the session or until explicitly dropped.
CTE Example: WITH SalesCTE AS ( SELECT SalesPerson, SUM(SalesAmount) AS TotalSales FROM Sales GROUP BY SalesPerson ) SELECT * FROM SalesCTE WHERE TotalSales > 1000;
Q3: How does the ROW_NUMBER() function work?
Assigns sequential numbers to rows within a partition.
SELECT Name, DeptID, ROW_NUMBER() OVER(PARTITION BY DeptID ORDER BY Salary DESC) AS RowNum FROM Employees;
Q4: Difference between a stored procedure and a function?
Stored procedures can perform actions like INSERT/UPDATE. Functions return values and cannot modify database state.
-- Stored Procedure CREATE PROCEDURE UpdateSalary @EmpID INT, @Amount DECIMAL AS UPDATE Employees SET Salary = Salary + @Amount WHERE EmployeeID = @EmpID; GO -- Scalar Function CREATE FUNCTION GetSalary(@EmpID INT) RETURNS DECIMAL AS BEGIN RETURN (SELECT Salary FROM Employees WHERE EmployeeID = @EmpID) END; GO
Q5: What happens if you use SELECT * in a JOIN on large tables?
SELECT * retrieves all columns, causing more I/O and memory usage. It's better to select only needed columns.
SELECT e.Name, d.Name AS Dept FROM Employees e JOIN Departments d ON e.DeptID = d.DeptID; -- Avoid: SELECT * FROM Employees e JOIN Departments d ...
Q6: What is a NULL in SQL and how does it behave in comparisons?
NULL represents unknown/missing value. Use IS NULL to check.
SELECT Name FROM Employees WHERE ManagerID IS NULL; SELECT Name FROM Employees WHERE ManagerID = NULL; -- wrong!
Q7: Difference between DELETE and TRUNCATE?
DELETE removes rows and fires triggers. TRUNCATE is faster, resets identity, and cannot be rolled back in some cases.
DELETE FROM Employees WHERE DeptID = 5; TRUNCATE TABLE Employees;
Q8: What is the effect of using NOLOCK in a SELECT query?
Reads data without locks; may return dirty data.
SELECT * FROM Employees WITH (NOLOCK);
Q9: How does SQL Server handle implicit vs explicit conversions?
Implicit conversions happen automatically. Explicit conversions use CAST or CONVERT.
-- Implicit SELECT 'EmployeeID: ' + EmployeeID FROM Employees; -- Explicit SELECT 'EmployeeID: ' + CAST(EmployeeID AS VARCHAR(10)) FROM Employees;
Q10: Difference between clustered and non-clustered indexes?
Clustered determines physical order. Non-clustered is separate and points to data rows.
-- Clustered index CREATE CLUSTERED INDEX IX_Employees_DeptID ON Employees(DeptID); -- Non-clustered index CREATE NONCLUSTERED INDEX IX_Employees_Name ON Employees(Name);
Q11: Difference between UNION and UNION ALL?
UNION removes duplicates. UNION ALL keeps all rows.
SELECT Name FROM Employees UNION SELECT Name FROM Contractors; SELECT Name FROM Employees UNION ALL SELECT Name FROM Contractors;
Q12: How do you prevent deadlocks in SQL Server?
Keep transactions short, use proper indexing, and access tables in same order.
BEGIN TRAN UPDATE Accounts SET Balance = Balance - 100 WHERE ID = 1; UPDATE Accounts SET Balance = Balance + 100 WHERE ID = 2; COMMIT TRAN;
Q13: Difference between CROSS APPLY and OUTER APPLY?
CROSS APPLY returns only matching rows; OUTER APPLY returns all rows from left table.
-- CROSS APPLY SELECT e.Name, s.Sales FROM Employees e CROSS APPLY ( SELECT TOP 1 SalesAmount AS Sales FROM Sales WHERE Sales.SalesPersonID = e.EmployeeID ORDER BY SaleDate DESC ) s; -- OUTER APPLY SELECT e.Name, s.Sales FROM Employees e OUTER APPLY ( SELECT TOP 1 SalesAmount AS Sales FROM Sales WHERE Sales.SalesPersonID = e.EmployeeID ORDER BY SaleDate DESC ) s;
Q14: Scalar vs Table-Valued Function?
Scalar returns single value; table-valued returns table.
-- Scalar function SELECT dbo.GetSalary(101); -- Table-valued function SELECT * FROM dbo.GetEmployeeSales(101);
Q15: How does SQL Server handle transactions with isolation levels?
Controls locking and consistency.
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE; BEGIN TRAN SELECT * FROM Accounts WHERE ID = 1; COMMIT TRAN;
Q16: What is a deadlock and how can you detect it?
Two transactions block each other. Detect with system_health session or Profiler.
-- Example deadlock scenario -- Transaction 1 locks Row A then Row B -- Transaction 2 locks Row B then Row A
Q17: How does SQL Server optimize queries with indexes?
Query optimizer chooses the most efficient path using indexes.
SELECT Name FROM Employees WHERE DeptID = 5; -- uses IX_Employees_DeptID
Q18: Difference between EXISTS and IN?
EXISTS returns TRUE if subquery has rows; IN checks values.
-- EXISTS SELECT Name FROM Employees e WHERE EXISTS ( SELECT 1 FROM Sales s WHERE s.SalesPersonID = e.EmployeeID ); -- IN SELECT Name FROM Employees WHERE EmployeeID IN (SELECT SalesPersonID FROM Sales);
Q19: What is a transaction log?
Records all database changes; used for rollback and recovery.
-- Cannot query directly, but view log backup BACKUP LOG MyDB TO DISK = 'C:\Logs\MyDB_Log.bak';
Q20: Difference between CHAR and VARCHAR?
CHAR = fixed length, VARCHAR = variable length.
DECLARE @c CHAR(10) = 'Test'; -- stores 'Test ' DECLARE @v VARCHAR(10) = 'Test'; -- stores 'Test'
