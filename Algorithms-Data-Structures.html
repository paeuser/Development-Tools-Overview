Algorithms & Data Structures Cheat Sheet for Beginners (C#)

Welcome! This beginner-friendly guide covers core concepts and examples from Codility Developer Training, using C# samples you can run and practice.

1. Iterations (Loops)

Loops repeat code multiple times, commonly using for or while.

// Print numbers 1 to 5
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}

Tip: Always ensure loops will end to avoid infinite loops.

2. Arrays

Arrays hold multiple values of the same type and use zero-based indexing.

int[] numbers = { 2, 4, 6, 8 };
Console.WriteLine(numbers[2]); // Output: 6

You can access or update values by their index.

3. Time Complexity (Big O)

What is it? Big O notation tells you how your program’s runtime increases when input size (N) grows.

Common cases:

  • O(1) — Constant time: same time regardless of input size.
  • O(N) — Linear time: time grows proportionally to input size.
  • O(N²) — Quadratic time: time grows proportional to square of input size, usually slow.

Examples:

// O(1) - Constant time example
int GetFirst(int[] A)
{
    return A[0]; // Direct access, no loop
}

// O(N) - Linear time example
int Sum(int[] A)
{
    int sum = 0;
    for (int i = 0; i < A.Length; i++)
    {
        sum += A[i];
    }
    return sum;
}

// O(N²) - Quadratic time example
bool HasPairSumZero(int[] A)
{
    for (int i = 0; i < A.Length; i++)
    {
        for (int j = 0; j < A.Length; j++)
        {
            if (A[i] + A[j] == 0) return true;
        }
    }
    return false;
}
Tip: Avoid nested loops when possible. Aim for linear or better time complexity.

4. Counting Elements (Distinct Values)

Use HashSet<T> to keep track of unique values efficiently.

public int CountDistinct(int[] A)
{
    var seen = new HashSet<int>();
    foreach (var item in A)
    {
        seen.Add(item);
    }
    return seen.Count;
}

This runs in O(N) time, which is efficient.

5. Prefix Sums

Calculate cumulative sums to quickly find sums over any sub-range.

int[] prefix = new int[A.Length + 1];
for (int i = 1; i <= A.Length; i++)
{
    prefix[i] = prefix[i - 1] + A[i - 1];
}

// Sum from index l to r: prefix[r + 1] - prefix[l]

6. Sorting

Sort arrays easily with built-in functions:

Array.Sort(A);

Sorting usually takes O(N log N) time.

7. Stacks and Queues

Stacks: Last-In-First-Out (LIFO)

Stack<int> stack = new Stack<int>();
stack.Push(10);
stack.Push(20);
int top = stack.Pop(); // top = 20

Queues: First-In-First-Out (FIFO)

Queue<int> queue = new Queue<int>();
queue.Enqueue(10);
queue.Enqueue(20);
int front = queue.Dequeue(); // front = 10

8. Sample Problem: Frog Jumps

Find the minimal number of jumps from position X to a position ≥ Y, with fixed jump length D.

public int FrogJumps(int X, int Y, int D)
{
    int distance = Y - X;
    // (distance + D - 1) / D does integer ceiling division for jumps count
    return (distance + D - 1) / D;
}

9. Sample Problem: Count Divisible Numbers

Count how many numbers between A and B (inclusive) are divisible by K.

public int CountDivisible(int A, int B, int K)
{
    return (B / K) - ((A - 1) / K);
}

10. What Not to Do

  • Don't write unnecessary nested loops (avoid O(N²) if possible).
  • Don't forget edge cases like empty arrays or zero values.
  • Don't ignore performance; test with big inputs.

11. Quick Tips

  • Use HashSet<T> to track unique items efficiently.
  • Remember, O(1) < O(log N) < O(N) < O(N²) in speed.
  • Use prefix sums for quick range sum queries.
