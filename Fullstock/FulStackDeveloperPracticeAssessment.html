Database Theory & SQL (Questions 31-40)

31. What is the primary purpose of a primary key in a database table?

  • To sort data
  • To uniquely identify each record in a table
  • To create relationships
  • To store large data

32. What is the difference between INNER JOIN and LEFT JOIN?

  • No difference
  • INNER JOIN returns only matching records, LEFT JOIN returns all left table records
  • LEFT JOIN is faster
  • INNER JOIN includes NULL values

33. What is database normalization?

  • Making databases larger
  • The process of organizing data to minimize redundancy
  • Deleting data
  • Creating backups

34. What is a foreign key?

  • A key from another country
  • A field that creates a link between two tables
  • A primary key
  • An encrypted key

35. Which SQL command is used to modify existing records?

  • INSERT
  • UPDATE
  • SELECT
  • CREATE

36. What is an index in a database?

  • A table of contents
  • A data structure that improves query performance
  • A backup file
  • A user account

37. What does ACID stand for in database transactions?

  • Atomicity, Consistency, Isolation, Durability
  • Access, Control, Integration, Data
  • Authentication, Certification, Identity, Database
  • Application, Connection, Interface, Design

38. What is the difference between SQL Server and PostgreSQL?

  • No difference
  • SQL Server is Microsoft's RDBMS, PostgreSQL is open-source
  • PostgreSQL is only for web applications
  • SQL Server doesn't support SQL

39. What is a stored procedure?

  • A backup method
  • A precompiled collection of SQL statements
  • A data type
  • A table relationship

40. What is the purpose of the GROUP BY clause in SQL?

  • To sort results
  • To group rows that have the same values in specified columns
  • To join tables
  • To filter results
