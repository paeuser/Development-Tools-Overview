.NET Concepts

ADO.NET

ADO.NET is a data access technology from Microsoft that provides communication between relational and non-relational systems through a common set of components. // Example of using ADO.NET to query a database using (SqlConnection connection = new SqlConnection(connectionString)) { SqlCommand command = new SqlCommand("SELECT * FROM Customers", connection); connection.Open(); SqlDataReader reader = command.ExecuteReader(); while (reader.Read()) { Console.WriteLine(reader["CompanyName"]); } reader.Close(); }

Dependency Injection

Dependency Injection (DI) is a design pattern that implements Inversion of Control (IoC) between classes and their dependencies. // Example of dependency injection in ASP.NET Core public void ConfigureServices(IServiceCollection services) { // Register services for DI services.AddScoped(); services.AddControllers(); } // Using DI in a controller public class MyController : Controller { private readonly IMyService _myService; public MyController(IMyService myService) { _myService = myService; } }

Entity Framework Core (EF Core)

Entity Framework Core is a lightweight, extensible, open source, and cross-platform version of Entity Framework data access technology. // Example of using EF Core to query data public class BloggingContext : DbContext { public DbSet Blogs { get; set; } public DbSet Posts { get; set; } } // Querying data using (var context = new BloggingContext()) { var blogs = context.Blogs .Where(b => b.Rating > 3) .OrderBy(b => b.Url) .ToList(); }

Middleware

Middleware is software that's assembled into an application pipeline to handle requests and responses in ASP.NET Core. // Example of custom middleware in ASP.NET Core public class CustomMiddleware { private readonly RequestDelegate _next; public CustomMiddleware(RequestDelegate next) { _next = next; } public async Task InvokeAsync(HttpContext context) { // Do something before the request await _next(context); // Do something after the request } } // Registering middleware in Startup.cs public void Configure(IApplicationBuilder app) { app.UseMiddleware(); }

DTO

DTO (Data Transfer Object) is a design pattern used to transfer data between software application subsystems. // Example of a DTO class public class UserDto { public int Id { get; set; } public string FirstName { get; set; } public string LastName { get; set; } public string Email { get; set; } // Unlike the User entity, the DTO might exclude sensitive data like passwords } // Using DTO in a controller [HttpGet("{id}")] public ActionResult GetUser(int id) { var user = _userRepository.GetUser(id); var userDto = _mapper.Map(user); return Ok(userDto); }

Unit Testing

Unit testing is a software testing method where individual units/components of software are tested in isolation from the rest of the system. // Example unit test with xUnit public class CalculatorTests { [Fact] public void Add_TwoNumbers_ReturnsSum() { // Arrange var calculator = new Calculator(); // Act var result = calculator.Add(3, 5); // Assert Assert.Equal(8, result); } } // Example of a class being tested public class Calculator { public int Add(int a, int b) => a + b; }

Web API Concepts

REST

REST (Representational State Transfer) is an architectural style for designing networked applications. RESTful systems typically communicate over HTTP with these principles: - Client-server architecture - Statelessness - Cacheability - Uniform interface - Layered system REST APIs use HTTP methods (GET, POST, PUT, DELETE) to perform operations on resources identified by URLs.

HTTP Status Codes

HTTP status codes are three-digit numbers returned by servers to indicate the result of a client's request. Common categories include: - 1xx (Informational): Request received, continuing process - 2xx (Success): Action successfully received, understood, and accepted - 3xx (Redirection): Further action needs to be taken to complete the request - 4xx (Client Error): Request contains bad syntax or cannot be fulfilled - 5xx (Server Error): Server failed to fulfill a valid request Common status codes: 200 (OK), 201 (Created), 400 (Bad Request), 401 (Unauthorized), 404 (Not Found), 500 (Internal Server Error).

API Gateway

An API Gateway acts as a reverse proxy, handling requests routing, auth, rate limiting, caching, and aggregating services. // Example of API Gateway configuration (pseudo-code) apiGateway .route('/users/*') .authenticate() .rateLimit(100req/hour) .cache(5min) .forwardTo('user-service');

Webhook

User-defined HTTP callbacks triggered by events, allowing real-time notifications to clients. // Example of handling a webhook in ASP.NET Core [HttpPost("webhook")] public IActionResult HandleWebhook([FromBody] WebhookPayload payload) { // Process the webhook payload _backgroundJobService.ProcessWebhook(payload); return Ok(); }

OpenAPI

OpenAPI specification is a standard format to describe REST APIs, enabling automated documentation and client generation. // Example OpenAPI snippet openapi: 3.0.0 info: title: Sample API version: 1.0.0 paths: /users: get: summary: Returns a list of users responses: '200': description: A list of users content: application/json: schema: type: array items: $ref: '#/components/schemas/User'

Security Concepts

JSON Web Token (JWT)

JWT is an open standard (RFC 7519) that defines a compact and self-contained way for securely transmitting information between parties as a JSON object. // Example JWT structure // Header: {"alg": "HS256", "typ": "JWT"} // Payload: {"sub": "1234567890", "name": "John Doe", "iat": 1516239022} // Signature: HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), secret) // Example of creating a JWT in C# var tokenHandler = new JwtSecurityTokenHandler(); var key = Encoding.ASCII.GetBytes("your-secret-key"); var tokenDescriptor = new SecurityTokenDescriptor { Subject = new ClaimsIdentity(new[] { new Claim("id", "user123") }), Expires = DateTime.UtcNow.AddHours(1), SigningCredentials = new SigningCredentials(new SymmetricSecurityKey(key), SecurityAlgorithms.HmacSha256Signature) }; var token = tokenHandler.CreateToken(tokenDescriptor); var jwt = tokenHandler.WriteToken(token);

CORS

CORS (Cross-Origin Resource Sharing) is a mechanism that allows restricted resources on a web page to be requested from another domain outside the domain from which the first resource was served. // Example of enabling CORS in ASP.NET Core public void ConfigureServices(IServiceCollection services) { services.AddCors(options => { options.AddPolicy("AllowMyOrigin", builder => builder.WithOrigins("http://example.com") .AllowAnyHeader() .AllowAnyMethod()); }); } public void Configure(IApplicationBuilder app) { app.UseCors("AllowMyOrigin"); }

OAuth 2.0

OAuth 2.0 is an authorization framework that allows clients limited access to user resources via tokens. // OAuth 2.0 flow example 1. Client redirects user to authorization server 2. User authenticates and grants permission 3. Authorization server redirects back to client with authorization code 4. Client exchanges authorization code for access token 5. Client uses access token to access protected resources

Authentication

Authentication verifies user identity; authorization determines what they're allowed to do. // Example of authentication in ASP.NET Core [HttpPost("login")] public async Task Login([FromBody] LoginModel model) { var user = await _userManager.FindByNameAsync(model.Username); if (user != null && await _userManager.CheckPasswordAsync(user, model.Password)) { var token = await GenerateJwtToken(user); return Ok(new { Token = token }); } return Unauthorized(); }

Authorization

Authorization determines what a user is allowed to do after authentication. // Example of authorization in ASP.NET Core [Authorize(Roles = "Administrator")] [HttpGet("admin-data")] public IActionResult GetAdminData() { // Only users with Administrator role can access this return Ok(adminData); } [Authorize(Policy = "RequireEditorRole")] [HttpPost("edit-content")] public IActionResult EditContent([FromBody] ContentModel content) { // Only users satisfying the policy can access this return Ok(); }

Data Access Concepts

DbContext

DbContext is a primary class in Entity Framework that represents a session with the database and provides APIs for data operations. // Example of DbContext usage public class AppDbContext : DbContext { public DbSet Products { get; set; } public DbSet Categories { get; set; } protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder) { optionsBuilder.UseSqlServer("YourConnectionString"); } } // Using DbContext in a repository public class ProductRepository { private readonly AppDbContext _context; public ProductRepository(AppDbContext context) { _context = context; } public async Task GetProductById(int id) { return await _context.Products.FindAsync(id); } }

Disconnected Architecture

Disconnected Architecture in ADO.NET refers to working with data offline using DataSet and DataAdapter objects. // Example of disconnected architecture var adapter = new SqlDataAdapter("SELECT * FROM Products", connection); var dataSet = new DataSet(); adapter.Fill(dataSet, "Products"); // Work with data offline foreach (DataRow row in dataSet.Tables["Products"].Rows) { Console.WriteLine(row["ProductName"]); } // Later, update the database with changes adapter.Update(dataSet, "Products");

PostgreSQL

PostgreSQL is a powerful, open source object-relational database system. // Example of using PostgreSQL with EF Core services.AddDbContext(options => options.UseNpgsql(Configuration.GetConnectionString("PostgresConnection"))); // PostgreSQL specific query var results = await _context.Products .FromSqlRaw("SELECT * FROM products WHERE price > {0}", 50) .ToListAsync();

SQL Server

Microsoft SQL Server is a relational database management system developed by Microsoft. // Example of using SQL Server with EF Core services.AddDbContext(options => options.UseSqlServer(Configuration.GetConnectionString("DefaultConnection"))); // SQL Server specific query using LIKE var results = await _context.Products .Where(p => EF.Functions.Like(p.Name, "%search%")) .ToListAsync();
