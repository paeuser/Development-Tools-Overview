Session and State Management in .NET

1. Introduction

Web applications are stateless, meaning the server does not automatically remember user interactions across HTTP requests. State management allows data to persist across multiple requests.

2. Client-Side State Management

a) Cookies

// Set a cookie
Response.Cookies["UserName"].Value = "Eric";
Response.Cookies["UserName"].Expires = DateTime.Now.AddDays(1);

// Read a cookie
string user = Request.Cookies["UserName"]?.Value;

b) Query Strings

// URL: www.example.com/page.aspx?userid=123
string userId = Request.QueryString["userid"];

c) Hidden Fields

<asp:HiddenField ID="hdnValue" runat="server" Value="123" />

// Read value in code-behind
string val = hdnValue.Value;

d) Local Storage / Session Storage (JavaScript)

// Set value
localStorage.setItem('UserName', 'Eric');

// Get value
var user = localStorage.getItem('UserName');

3. Server-Side State Management

a) Session State

// Store data in session
Session["UserName"] = "Eric";

// Retrieve data from session
string user = Session["UserName"]?.ToString();

b) Application State

// Store data in application
Application["TotalUsers"] = 100;

// Retrieve data
int total = (int)Application["TotalUsers"];

c) Cache

// Store data in cache
Cache["Products"] = productList;

// Retrieve data
var products = Cache["Products"] as List<Product>;

4. Session Modes in ASP.NET

// Web.config example for InProc session mode
<sessionState mode="InProc" timeout="20" />

// StateServer mode
<sessionState mode="StateServer" stateConnectionString="tcpip=127.0.0.1:42424" timeout="20" />

// SQLServer mode
<sessionState mode="SQLServer" sqlConnectionString="data source=127.0.0.1;user id=sa;password=yourpassword" timeout="20" />

5. Session Expiration and Security

// Set session timeout in minutes
Session.Timeout = 30;

// Always use HTTPS and secure cookies for sensitive data

6. Full ASP.NET Example: Saving User Name in Session

<%@ Page Language="C#" AutoEventWireup="true" CodeFile="SessionExample.aspx.cs" Inherits="SessionExample" %>
<html>
<body>
<form id="form1" runat="server">
    <asp:Label ID="lblMessage" runat="server" Text="" /><br />
    <asp:TextBox ID="txtName" runat="server" /><br />
    <asp:Button ID="btnSave" runat="server" Text="Save" OnClick="btnSave_Click" />
</form>
</body>
</html>

// Code-behind (SessionExample.aspx.cs)
protected void btnSave_Click(object sender, EventArgs e)
{
    Session["UserName"] = txtName.Text;
    lblMessage.Text = "Name saved in session!";
}

protected void Page_Load(object sender, EventArgs e)
{
    if(Session["UserName"] != null)
        lblMessage.Text = "Hello, " + Session["UserName"].ToString();
}
