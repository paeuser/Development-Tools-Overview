C# Generics and LINQ

What are Generics?

Generics allow you to write type-safe, reusable code. Instead of writing the same logic for multiple data types, you write it once using a placeholder (like <T>) and use it for any type.

Generic Function Example: PrintValue


// Prints any value and its type
PrintValue<int>(123);
PrintValue<string>("Hello, Generics!");
PrintValue<double>(45.67);

void PrintValue<T>(T value)
{
    Console.WriteLine($"Value: {value} | Type: {typeof(T)}");
}

Generic Swap Function


int a = 5;
int b = 10;
Console.WriteLine($"\nBefore Swap: a = {a}, b = {b}");
SwapValues<int>(ref a, ref b);
Console.WriteLine($"After Swap: a = {a}, b = {b}");

string str1 = "Apple", str2 = "Banana";
Console.WriteLine($"\nBefore Swap (string): str1 = {str1}, str2 = {str2}");
SwapValues<string>(ref str1, ref str2);
Console.WriteLine($"After Swap (string): str1 = {str1}, str2 = {str2}");

void SwapValues<T>(ref T x, ref T y)
{
    T temp = x;
    x = y;
    y = temp;
}

Generic Class Example: Box<T>


Box<int> intBox = new Box<int> { Value = 99 };
intBox.Show();

Box<string> strBox = new Box<string> { Value = "Hello, Box!" };
strBox.Show();

class Box<T>
{
    public T Value;

    public void Show()
    {
        Console.WriteLine($"Box contains: {Value} | Type: {typeof(T)}");
    }
}
