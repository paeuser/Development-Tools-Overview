Write a function:

class Solution { public int solution(int A, int B, int K); }
content_copy

that, given three integers A, B and K, returns the number of integers within the range [A..B] that are divisible by K, i.e.:

{ i : A ≤ i ≤ B, i mod K = 0 }

For example, for A = 6, B = 11 and K = 2, your function should return 3, because there are three numbers divisible by 2 within the range [6..11], namely 6, 8 and 10.

Write an efficient algorithm for the following assumptions:

A and B are integers within the range [0..2,000,000,000];
K is an integer within the range [1..2,000,000,000];
A ≤ B.

✅ Problem Summary

You are given:

    A, B: range endpoints

    K: divisor

You need to count how many integers i in the range [A..B] are divisible by K.
🔍 Example:

A = 6, B = 11, K = 2
Divisible values = {6, 8, 10}
Result = 3

❌ Brute Force (Too Slow for Large Ranges):

int count = 0;
for (int i = A; i <= B; i++) {
    if (i % K == 0) count++;
}

This works, but is too slow for large values (A and B can be up to 2,000,000,000).
✅ Efficient Math-Based Formula (O(1) time)

We calculate how many numbers from 1 to B are divisible by K:

int divisibleUpToB = B / K;

Then subtract how many numbers from 1 to A - 1 are divisible by K:

int divisibleUpToAminus1 = (A - 1) / K;

Finally:

return divisibleUpToB - divisibleUpToAminus1;

✅ Final Java Code

class Solution {
    public int solution(int A, int B, int K) {
        return (B / K) - ((A - 1) / K);
    }
}

💡 Why this works:

    Every multiple of K forms an arithmetic sequence: K, 2K, 3K, ...

    So, the number of elements up to B = floor(B / K)

    Same for A - 1, then subtract to get count in range [A..B]

🔢 Example Walkthrough:

A = 6, B = 11, K = 2

B / K     = 11 / 2 = 5   → multiples up to 11: {2, 4, 6, 8, 10}
(A - 1) / K = 5 / 2 = 2   → multiples up to 5: {2, 4}

So answer = 5 - 2 = 3 → {6, 8, 10}
